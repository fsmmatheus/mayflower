Política de Privacidade

Mayflower Studio · atualizada em 24 de outubro de 2026

O Mayflower Studio é um aplicativo de uso pessoal. Esta política explica quais dados ele acessa e como são tratados.

Dados acessados

Com a autorização do dono da conta, pelo login do Google, o app acessa a API de Dados do YouTube e a API do YouTube Analytics para:

  • enviar, agendar e editar vídeos, títulos, descrições e thumbnails do próprio canal;
  • ler informações e estatísticas do próprio canal (views, retenção, inscritos).

Como os dados são usados

Os dados servem apenas para produzir e planejar os vídeos do próprio canal. Eles ficam guardados somente no computador do dono do app. Não são vendidos, compartilhados com terceiros nem usados para publicidade.

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Serviços do YouTube

O app usa os Serviços de API do YouTube. Ao usá-lo, você também concorda com os Termos de Serviço do YouTube e com a Política de Privacidade do Google.

Como remover o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Os dados guardados no computador podem ser apagados pelo próprio dono.
